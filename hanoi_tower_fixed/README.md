# FastAPI 하노이의 탑 — PyCharm 오류 수정판

이 버전은 시작 버튼을 누를 때 `오류: 이동 횟수를 확인하지 못했습니다.`가 발생하는 문제를 해결합니다.
총 이동 횟수는 브라우저에서 정수(BigInt)로 정확하게 계산하며, FastAPI 이동 API가 없거나 오류를 반환할 경우 브라우저가 **이동 순서를 직접 계산하여 애니메이션을 계속 실행**합니다.

## PyCharm에서 실행 (Python 3.10 이상)

1. 이전 PyCharm 실행 창의 **빨간 정지 버튼**을 눌러 기존 서버를 종료합니다. 터미널에서 `uvicorn`을 실행했다면 `Ctrl+C`로 종료합니다. 같은 포트 8000을 사용 중인 구버전 서버가 없도록 확인하세요.
2. 다운로드한 ZIP을 풀고 **`hanoi_tower_fixed` 폴더 전체**를 PyCharm에서 엽니다. HTML 파일만 복사하지 말고 `main.py`와 `templates/index.html`을 함께 사용해야 합니다.
3. PyCharm의 Python 인터프리터를 선택한 뒤 터미널에서 `python -m pip install -r requirements.txt`를 실행합니다.
4. `main.py`를 우클릭 → **Run 'main'** (또는 터미널에서 `python main.py`)을 실행합니다.
5. 브라우저에서 **http://127.0.0.1:8000/** 에 접속합니다. 예전 화면이 남아 있으면 `Ctrl+Shift+R`로 강력 새로고침합니다.

### 서버 버전 확인 (중요)

브라우저에서 http://127.0.0.1:8000/api/config 에 접속합니다. 아래처럼 나타나야 합니다.

```json
{"max_disks":10000,"max_visual_disks":1000,"version":"2.1-fixed"}
```

`version`이 없거나 404라면 예전 서버나 다른 프로그램이 포트 8000을 사용하고 있는 것입니다. 기존 실행을 중단한 후 최신 `main.py`를 실행하세요.

## 주요 기능

- 1~10,000개의 원판 수 입력, 10,000개 초과 시 안내 문구
- 1~1,000개까지 상승 → 수평 이동 → 하강 애니메이션
- 일시정지/재개, 속도 조절(0.25~5배), 초기화
- **결과 바로 보기:** `2^n - 1`을 정확한 10진수로 출력하고 복사
- 1,001개 이상은 화면 성능 문제로 애니메이션 대신 결과 계산만 지원
- FastAPI는 이동 전체를 미리 생성하지 않고 최대 100개씩 계산해 전달
- 서버 이동 API 오류 시 클라이언트가 원판 이동을 직접 계산하는 안전장치 제공

원판이 많을수록 모든 이동을 완료하는 데 천문학적인 시간이 필요합니다.

## 선택 사항: API 검사

- http://127.0.0.1:8000/api/hanoi/3 에서 `total_moves`가 `"7"`인지 확인
- http://127.0.0.1:8000/api/hanoi/3/moves?start=1&limit=10 에서 이동 목록 확인
- 개발용 검증 도구 설치: `python -m pip install httpx`
- `python -m unittest discover -s tests -v`
